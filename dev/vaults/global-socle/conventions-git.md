# Conventions git

## Branches

- `main` est protégée : toute modification passe par une demande de fusion relue.
- Les branches de travail sont nommées `feature/<ticket>-<résumé>`.

## Messages de commit

Un message de commit commence par un verbe à l'indicatif présent : « Ajoute », « Corrige ».
